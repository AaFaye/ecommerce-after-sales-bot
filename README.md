# 电商售后智能助手

基于扣子编程开发的电商售后 AI 智能体，已上架扣子商店，可公开体验。

## 项目简介

本智能体基于《电商售后》知识库，回答退换货、物流、退款、客服话术四类问题，严格按规则作答并标注适用条件。项目覆盖知识库构建、提示词设计、测试集评测与上线发布的完整流程。

## 核心功能

- **规则问答**：解答退货运费、七天无理由退货、三包质量等售后问题，并标注适用条件。
- **边界识别**：判断“影响二次销售”等边界情形，按知识库规则给出处理结论。
- **知识库问答（RAG）**：基于《电商售后》知识库检索作答，减少规则编造。
- **客服话术生成**：按场景输出可直接使用的售后回复。

## 技术要点

- **开发平台**：扣子编程
- **核心技术**：提示词工程、知识库检索增强（RAG）、工作流编排
- **知识库**：《电商售后》（含三包规定、退换货规则、客服规范）
- **评测方式**：按退换货、物流、退款、客服话术四类场景编写测试集，逐条核对回复是否符合规则

## 项目亮点（AI 数据评测视角）

1. **知识库构建**：把非结构化的售后条款整理成结构化知识，用于检索问答。
2. **提示词约束**：通过系统提示词限定回答范围与输出格式，减少无效回复。
3. **评测闭环**：针对核心场景编写测试集，核对回复的合规性与准确性，再据此调整提示词和知识库。
4. **完整上线**：完成开发、调试、评测到商店上架的闭环。
